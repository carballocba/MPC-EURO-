# GHOST 2.4.2 - Quick Start

GHOST is a stereo glitch effect for live buffer manipulation, repeat, reverse and generative rhythmic interventions. Original MPC One / Hakai 3.9.1 audio operation is user-confirmed. Other hardware and firmware are not physically certified.

## Start playing
1. Save a copy of your project. Add GHOST as a Drum Program insert and play a simple drum loop.
2. Begin with MIX low. Raise it gradually to hear the processed signal.
3. In LIVE, enable LIVE REPEAT. Move FRAGMENT to change the repetition length. Turn Repeat off to return to the incoming groove.
4. Try REVERSE with enough incoming history. FREEZE/HELD protects material from incoming audio.
5. CAPTURE is a toggle: tap once to begin a take, tap again to finish into HELD. The configurable maximum is eight seconds; FULL ends the take automatically.
6. CLEAN stops processing and generation without deleting the captured take.

## Musical controls
ACTIVITY controls Performance intervention; CHARACTER controls variety and unpredictability. FRAGMENT sets the time scale. EVOLUTION uses Motion and depends on enabled routes. POSITION is buffer read position, not reverb. MIX blends original and processed audio.

## Random Repeat
Choose INDEPENDENT for automatic Repeat/Fragment phrases without Performance. Choose PERFORMANCE for the existing Performance engine. BOTH combines them. Use probability, intensity, variation, rate and hold to shape the phrase. Activity zero cancels automatic Random Repeat in BOTH. Manual changes have priority for an override window; generation may then resume. Random Repeat does not capture or freeze material automatically.

## Presets and navigation
The 16 factory programs and 52 external FXP files are preserved. FXP do not contain captured audio, and automatic Hakai browser import is not demonstrated. Do not assume that a buffer-dependent preset will sound without input/history. Use the host's native page navigation and Q-Link banks. No parameter or assignment changed for this distribution.

## Installation status
The community package uses device-side shell scripts with the official -y, -n and -t interface. Read INSTALL.md before running it. The corrected transactional installer is tested in offline simulations, not physically. The original computer-side recovery package remains a separate unchanged download.

## Safe projects and recovery
Save new RRF1 projects under new names. Older binaries may not read them; rollback restores files, not project formats. Keep backups outside GHOST. Use only the matching transaction's recovery plan, never a historical complete MPC.settings snapshot. The MPC screen can go black while its host service is intentionally stopped.
